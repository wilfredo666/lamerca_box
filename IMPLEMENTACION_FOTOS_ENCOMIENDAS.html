✨ Características Implementadas

  • Campo de foto opcional para cada encomienda
  • Captura desde cámara (PC o móvil) con capture="environment"
  • Validación de formato: JPEG, PNG, GIF, WEBP
  • Validación de tamaño: máximo 5MB
  • Feedback visual: emoji cambia de 📷 a ✅ al seleccionar
  • Nombres de archivo únicos: paquete_identificador-aleatorio.ext
  • Almacenamiento en assets/img/paquetes/, como las demás fotos de encomiendas
  • Validación de formato real y tamaño en el servidor antes de guardar
  • Validación en cliente (JavaScript) y servidor (PHP)

🔒 Validaciones Implementadas

Cliente (JavaScript)

  • Validación de tipo MIME (image/jpeg, image/png, image/gif, image/webp)
  • Validación de tamaño máximo (5MB)
  • Mensajes de error al usuario
  • Confirmación visual al seleccionar la foto sin retirar el campo del formulario

Servidor (PHP)

  • Validación is_uploaded_file()
  • Validación de tipo MIME con in_array()
  • Validación de tamaño de archivo
  • Sanitización de nombre de archivo
  • Verificación de permisos de directorio
  • Manejo seguro de errores de subida

Seguridad de la carga

  • El servidor comprueba MIME y contenido de imagen
  • Los archivos se guardan con extensión determinada por MIME verificado
  • Los nombres aleatorios evitan sobrescribir fotos existentes

💡 Casos de Uso

  • Documentar el estado físico de la encomienda al recibirla
  • Evidencia de contenido para reclamaciones
  • Verificación de código de barras o etiqueta
  • Foto de la envoltura o empaque
  • Registro visual para auditoría
